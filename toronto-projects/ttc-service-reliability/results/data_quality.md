# Data quality and metric definitions- Source is TTC reported delay events beginning 2025; coverage in this downloaded file is 2025-01-01 through 2026-08-31.- Raw records: 45,475; retained unique dated rows: 45,475.- The publisher's `Min Delay` is a reported operational measure. This analysis does not equate it to passenger-weighted minutes or system-wide lost service.- Missing dates are excluded. Duplicate `_id` values are removed. Blank categories are labeled `Unknown`. Negative reported delay values are excluded; missing/zero delay values are set to 0 only for additive sums and are separately countable.- Incident count and reported delay-minute sum answer different questions; repeated incident IDs/records are not treated as independent riders.- This is descriptive. An observed line, station, or time association does not imply that location or time caused the delay.
